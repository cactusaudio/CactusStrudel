This directory is an immutable, human-readable snapshot of the GUI immediately
before the v3 Producer Workspace rebuild.

- Annotated tag: `ui-v2-baseline-20260728-95f85f6`

The source copies, masked API readbacks, and two desktop screenshot sets are
listed and hashed in `manifest.json`.

`probe-renderer.mjs` was already modified by Bowei in the worktree. It is not a
GUI file, was deliberately excluded, and was not changed while this snapshot
was made.

## Restore choices

For a complete historical checkout, use the annotated tag in a separate
worktree. For a visual/source comparison without changing the live branch, use
the files under `source/runtime/`.

Do not restore credentials from this archive. The settings snapshot is masked
and exists only to document the old GUI/runtime shape.
