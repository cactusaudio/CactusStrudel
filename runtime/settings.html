Preferences

Syntax validator

After each generation, brain reads the code BEFORE render. Catches undefined samples/synths, missing setcpm, `$drums = ...` ReferenceError, broken chains, silent layers. Brain reviews only — never changes creative content.

Off — skip validation, render straight (~0s overhead)
Light — 1 comprehensive pass (parse + samples + playability in one prompt); typically 10-60s
Heavy — 3 focused passes (parse → samples/synths → playability/audibility); typically 30-180s, hard ceiling ~4 min

Developer Mode

⚠️ When enabled, the Opus brain gains full read/write/bash access to the repo — same as a peer Claude Code instance. It can edit source files (runtime/, scripts/, docs/, settings.html, etc.), create checkpoints, and run shell commands. Brain knowledge base lives in developer/ (auto-loaded). Audit log at producer-brain/dev-mode-audit.jsonl.

Brain still cannot: sudo, git push to remote, touch ~/.claude/, modify ~/.cactus-strudel/config.json directly, or write outside ROOT. Keep this OFF unless you want brain to act as platform engineer.

brain can READ repo + WRITE to producer-brain/ + developer/ + /tmp/ (sandbox)
⚠ also allow brain to modify SOFTWARE SOURCE (runtime/, settings.html, docs/, kernel/, etc.) + run bash. Only enable when you explicitly want brain to act as peer engineer.
