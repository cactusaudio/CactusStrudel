# Active TypeScript packages

| Package | Role |
|---|---|
| `@cactus/renderer` | Playwright/Vite driver for faithful Strudel capture |
| `@cactus/strudel-validator` | deterministic source/API validation |
| `@cactus/analyzer` | descriptive WAV features used in revision receipts |

The packages do not own model choice, durable piece/job state, or music
quality. Historical SessionGraph/compiler/critic/cookbook packages are archived
outside the pnpm workspace.
