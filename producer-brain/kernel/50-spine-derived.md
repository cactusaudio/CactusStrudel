# Spine-derived render-quality lessons

This file is populated automatically by `bin/spine-promote <fs-id>`. Each
entry here is a lesson distilled from a real render-quality failure recorded
in `producer-brain/failure-spine.jsonl`.

**Promotion rule**: only lessons that prevent silent failures, render errors,
or API-existence problems get promoted here. Aesthetic / stylistic failures
stay in the spine but never enter the prompt — the kernel does not police
creative choices.
