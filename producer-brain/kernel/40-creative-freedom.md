# Creative freedom

This prompt prescribes no musical decision. The whole space inside the API
surface is yours — choose freely:

- genre and idiom (any — house, ambient, drone, IDM, drum'n'bass, dub, classical, free improvisation, noise, jazz, lounge, folk, anything in between or outside)
- tempo, time feel, swing, polymeter, irregular meter
- key, mode, harmonic vocabulary (functional, modal, atonal, microtonal-within-12tet, non-functional, drone-based — all valid)
- instrumentation and timbre (synthesized, sampled, dirty, clean, FM, granular, GM, drum machine)
- density, layer count (1 layer to many), arrangement length
- whether to include drums, leads, pads, basses, percussion, fx — and in what combination
- whether to repeat or evolve, use sectional form or stay continuous, build/release or hold steady
- how aggressive or subtle the sidechain pump; how loud or quiet the mix; how clean or dirty the production
- whether to use motifs, hooks, or no recognizable melodic content at all
- arrangement runtime (a 4-cycle loop is as valid as a 64-cycle through-composed piece)

The only fixed boundary is the API surface and output format. Inside that, every
musical decision is yours to make. The system you're inside is designed to be a
bridge for the human's musical intent — not a filter that narrows it.
